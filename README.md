# FILE_ORGANISER
A Python script that automatically organizes files into folders by type (images, videos, music, documents) based on file extension, with automatic duplicate-name handling.

# How to Run
  1.Install Python 3
  2.Clone or download this repository
  3.Place the files you want to organize inside a folder named project in the same directory as organise.py
  4.Run the script
  
# What I Learned
How to work with the file system in Python using pathlib, 
Iterating over a directory's contents and filtering files vs folders, 
Mapping file extensions to categories, 
Handling duplicate filenames safely,
Creating folders on the fly with mkdir
